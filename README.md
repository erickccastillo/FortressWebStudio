# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is enabled on this template. See [this documentation](https://react.dev/learn/react-compiler) for more information.

Note: This will impact Vite dev & build performances.
You can also try [the experimental native React Compiler support in plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md#rust-react-compiler) by using `compiler: true` in the plugin options instead of using the Babel plugin.

## Expanding the Oxlint configuration

If you are developing a production application, we recommend enabling type-aware lint rules by installing `oxlint-tsgolint` and editing `.oxlintrc.json`:

```json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "plugins": ["react", "typescript", "oxc"],
  "options": {
    "typeAware": true
  },
  "rules": {
    "react/rules-of-hooks": "error",
    "react/only-export-components": ["warn", { "allowConstantExport": true }]
  }
}
```

See the [Oxlint rules documentation](https://oxc.rs/docs/guide/usage/linter/rules) for the full list of rules and categories.




Manual Comercial y Operativo
Ejecutivo de Ventas y Gestión de Clientes para Desarrollo Web
Objetivo del Puesto

El objetivo principal del Ejecutivo de Ventas es identificar oportunidades de negocio, generar interés en los servicios de desarrollo web, asesorar a los clientes durante el proceso comercial y cerrar proyectos rentables, manteniendo una comunicación constante entre el cliente y el desarrollador para asegurar la satisfacción del servicio.

1. Proceso Comercial
Etapa 1: Prospección

La primera responsabilidad consiste en contactar clientes potenciales y generar interés en la creación o mejora de su presencia digital.

Durante el contacto inicial, el objetivo no es vender inmediatamente, sino despertar la necesidad del cliente mediante preguntas como:

¿Cuenta actualmente con página web?
¿Recibe clientes por internet?
¿Acepta solicitudes de cotización en línea?
¿Sus competidores cuentan con una presencia digital profesional?
¿Su negocio aparece correctamente en Google?
Objetivo Principal

Conseguir una reunión o llamada consultiva para analizar el proyecto y entender las necesidades del cliente.

Etapa 2: Reunión de Descubrimiento

Durante la reunión se deberá identificar:

Información del Negocio
Nombre del negocio.
Giro comercial.
Ubicación.
Público objetivo.
Necesidades
¿Qué problema desea resolver?
¿Qué funcionalidades requiere?
¿Tiene contenido disponible?
¿Cuenta con logotipo o identidad visual?
Presupuesto

Es importante comprender el presupuesto antes de presentar cualquier propuesta formal.

Preguntas sugeridas:

¿Qué presupuesto tiene contemplado para este proyecto?
¿Ha solicitado cotizaciones anteriormente?
¿Qué expectativas tiene respecto a la página web?
Etapa 3: Presentación de la Solución

Una vez comprendidas las necesidades del cliente, se deberá explicar la propuesta de valor:

Diseño profesional y moderno.
Desarrollo personalizado.
Optimización para dispositivos móviles.

Dominio incluido.

Comunicación directa durante todo el proyecto.

11. Cargos Adicionales

Podrán aplicarse costos adicionales cuando:

El cliente solicite funcionalidades fuera del alcance inicial.
Existan cambios significativos posteriores a la aprobación del diseño.
Se requieran integraciones no contempladas inicialmente.
El proyecto aumente considerablemente su complejidad.

Toda modificación deberá aprobarse previamente por ambas partes mediante una nueva cotización o adenda al proyecto.
